# PADDOCK

**A experiência da Fórmula 1.** Site multipágina sobre a temporada 2026: equipes, circuitos, engenharia e bastidores.

**Acesse:** https://the-3-students.github.io/PADDOCK/

## Páginas

| Página | Conteúdo |
| --- | --- |
| Início | Apresentação do grid, circuitos, engenharia e bastidores |
| Sobre | Objetivo, justificativa, público-alvo e autores |
| A Ciência da Velocidade | Aerodinâmica, pneus e unidade de potência, com diagramas e glossário |
| O Arquivo PADDOCK | Galeria com filtro por categoria, busca e visualização ampliada |
| Contato | Formulário com validação e perguntas frequentes |

## Recursos

- Layout responsivo, do celular ao desktop
- Menu em tela cheia, navegável por teclado
- Filtro e busca na galeria, com mensagem para busca sem resultados
- Validação de formulário em JavaScript, sem envio de dados
- Animações de entrada com respeito a `prefers-reduced-motion`
- Semântica e acessibilidade: rótulos, ARIA e foco visível

## Tecnologias

HTML5, CSS3 e JavaScript puro, sem frameworks, bibliotecas ou etapa de build.
